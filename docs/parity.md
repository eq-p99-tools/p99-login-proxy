# Parity and intentional deviations

This document records differences between the legacy Python proxy and the native implementation.

## UI parity status

The native app matches the Python PySide6 reference for user-visible behavior:

- Five reference tabs (Proxy, SSO, Advanced, Log, Changelog) plus a sixth **Extras** tab for native-only settings
- Form layouts, tooltips, proxy mode persistence, SSO character tables, local account/character CRUD
- Tray menu (Show/Hide, Launch EQ, Check Updates, Exit), dynamic tooltip, login/minimize notifications
- Icon state switching (default / proxy-only / disabled) per backend icon set
- Exe-adjacent `proxyconfig.ini`, local CSVs and logs, compatible with Python 1.x installs

## Intentional improvements

| Area | Python | Native |
|------|--------|--------|
| Bind address | `0.0.0.0` default | `127.0.0.1` default; non-loopback requires explicit opt-in |
| TLS | `sso_verify_tls=False` allowed | Verified TLS required in production builds |
| Secrets | Plaintext INI/CSV | API tokens migrate to the OS credential store and are scrubbed from INI |
| Config path | CWD-relative `proxyconfig.ini` | Exe-adjacent `proxyconfig.ini` with unknown settings preserved |
| Client endpoint | Any non-upstream sender | Single tracked client; ambiguous senders rejected |
| Linux EQ launch | Wine `eqgame.exe patchme` | Wine `eqgame.exe patchme` when `wine` is on PATH |
| Extras tab | N/A | Secondary EQ path, skip-SSO list, prerelease toggle, lifecycle badge |
| Updater install | GitHub zip self-update | Same first-zip-asset rename/extract/relaunch flow |

## Wire compatibility

- Protocol golden fixtures in `crates/protocol/tests/fixtures/` are generated by `tools/generate_oracle.py` from the Python pure modules.
- Rust output matches Python oracle for: combined ACK+login, CS offset adjustment, bad-password classifier.

## Preserved legacy behavior (unless fixture proves otherwise)

- DES-CBC null padding, login credential NUL framing
- SSO bad-password retry: suppress LoginAccepted, forward other Combined subs, ACK, inject replay once
- Server-list filter prefixes: `project 1999`, `an interesting`
- Fragment assembler duplicate-sequence length accumulation (Python parity)
- Local character CSV schema (20-column flat format)
- EQ launch with `patchme` argument; optional Windows elevation when **as Admin** is checked; Linux launches via `wine`

## Removal conditions

- Loopback-only default may be relaxed when advanced UI + warning ship and operators document LAN use cases.
- Session-only secret fallback should be removed when Linux Secret Service detection is reliable in CI matrix.
- Extras tab controls may merge into Advanced when no longer native-only.
